# Website direction inspired by the premium social card

The shared `site-premium.css` layer applies to all five public pages. It carries the card's condensed uppercase display type, teal lighting, and compass motif into the live HTML design. Reading surfaces remain light; existing body sizes and page copy are preserved. The actual app screenshots remain interactive in Plan, Today, Journey, Coach order, with a CSS perspective treatment and one-row navigation.

Barlow Condensed Bold is self-hosted from Google Fonts, with its SIL Open Font License alongside the font. The lightweight compass SVG is decorative. The generated social-card bitmap is not used as a website background or replacement for the real screen viewer.

Validation: all five pages at 1440, 1100, 1024, 820, 780, 390, and 320 pixels; no horizontal overflow or clipped controls. Verified font loading, mobile menu, Escape handling, keyboard screen switching, and support FAQ expansion. No feedback messages were sent.

Approved for publication on September 8, 2026, with the ocean-wave hero background. The optimized background is `public/assets/website/hero-waves-v1.webp`; its source and generation prompt are documented in `hero-waves-prompt.md`.
